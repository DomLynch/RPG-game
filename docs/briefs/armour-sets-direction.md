## The rule (order matters)
1. **Silhouette first.** A set changes the fighter's outline at the fight camera (helm shape, shoulders, skirt/coat, shield). This is the readability gate the Armour lane already carries.
2. **Material second.** Bronze, blackened scale, rusted scrap, iron, gold-and-ivory: real PBR materials, not a hue on one mesh.
3. **Colour third.** The rank tint (live since #835) stays as the within-tier ladder; it never carries a tier on its own.
Otherwise "ruby, emerald, gold" are six reskins, which is exactly what Dom rejected.

## Sets are factions, not palettes
Each set reads as a civilisation or a faction. Working ladder (names are working names; Armour proposes the final six):
| Tier | Set | Read |
|---|---|---|
| Mid | Bronze Hoplite | classical, grounded, worn bronze + dark red cloth |
| Mid | Goblin Scrap-King | mismatched plates, chain, bone trophies, asymmetry; clever and nasty, never comic |
| High | Witch-Bound Emerald | blackened scale, emerald inserts, thin runes, dark cloth; occult, not "wizard robe" |
| Elite | Ruby Bloodforge | dark-red plate, ruby cores, black iron; brutal, oversized pauldrons |
| Elite | Obsidian Warlord | near-black volcanic plate, matte with lit edges, dull silver |
| Top | Imperial Sun-Gold | pale gold + bronze + ivory cloth, lion/griffin motifs, closed helm; prestigious, not "painted gold" |

Stats and set bonuses in the source text are NOT part of this: stats arrive with Origin season 1. Beta sets are looks only.
