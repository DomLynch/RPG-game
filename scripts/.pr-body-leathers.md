## What this changes
- `gear-defs.json` set `leathers` gets an **era** (`eras: [{ fromRecordVersion: 74, shape: armour +20, stamina +5, magicResist -25 }]`). `gearDeltas(set, coverage, quality, version)` takes the era's shape from that version; older records keep the old shape. A sheet fight is stamped no lower than the newest set era (`cast-penalty-era.ts`, same pattern as the cast penalty), so a record's version says which shape its sheet had. Plate and robes do not move. REACH[74] empty. Loader checks every era shape like a base shape, rising order.
- The worn **weapon** reaches the world fight: `gear-mount.ts weapon(carried)` (the server view's main hand, the same ledger `HeroLimit.weapon` checks) -> `main.ts` keeps one variable `rigWeapon` that both the rig and `hero()` read, so what he holds is what he swings. Only weapons whose art ships with the page (the ground models: longsword, knife, cleaver, gladius, estoc) are offered; any other worn weapon is the longsword. The rig re-arms between fights (equip file loads on demand); the sim hero is rebuilt at the next clean window as before. `trace()` now reports the weapon. `originsPreview.forceWeapon` is a local browser-check hook (the server would refuse a forged weapon's record).
